EB Client Nextgen follows a **Cumulative Update (CU)** release naming scheme. Each CU is a numbered increment that layers fixes, improvements, and new features on top of the previous release. The archive currently holds five Nextgen CUs — from CU3 through the current latest, CU7. Every CU is available in both distribution formats: a standalone offline HTML file and a deployable web file bundle.

<Note>
  **Always use CU7 for new deployments.** Older CUs remain in the archive strictly for compatibility testing, historical reference, and scenarios where a specific older behaviour is required.
</Note>

## Archive Folder Structure

Both distribution formats follow a predictable layout. The current latest always lives at the top level; every prior CU is nested inside an `Older Versions/` sub-folder.

```
Offline Downloads/
├── [LATEST] EB Client Nextgen CU7.html       ← always the current release
└── Older Versions/
    ├── [LATEST] EB Client Nextgen CU6.html
    ├── EB Client Nextgen CU5.html
    ├── EB Client Nextgen CU4.html
    └── EB Client Nextgen CU3.html

Web Files/
├── [LATEST] EB Client Nextgen CU7/           ← always the current release
│   ├── index.html

└── Older Versions/
    ├── EB Client Nextgen CU6/
    ├── EB Client Nextgen CU5/
    ├── EB Client Nextgen CU4/
    └── EB Client Nextgen CU3/
```

## When to Use an Older Version

<Tip>
  **99% of users should use CU7.** The Nextgen line is cumulative — every fix and feature from earlier CUs is already present in the latest release.
</Tip>

Legitimate reasons to reach for an older CU:

- **Compatibility testing** — reproducing a bug that was present in a specific version to verify it has been fixed in CU7.
- **Pinned environments** — a hosted deployment that has been specifically tested against a particular CU and should not be upgraded mid-session.
- **Historical reference** — understanding how a specific feature or UI element evolved across releases.

## The Legacy Build

The Legacy build is a separate, older client that predates the entire Nextgen line. It is **not** part of the CU versioning scheme and is not included in the CU3–CU7 archive.

<Warning>
  **Avoid the Legacy build** unless you specifically need motion blur. As stated in the project README: *"Avoid using the legacy version unless you really want motion blur, it performs worse than lite and is no longer developed."* The Nextgen "lite" renderer is faster in every measurable way, and the Legacy build receives no further fixes or updates.
</Warning>

| | Nextgen (CU3–CU7) | Legacy |
|---|---|---|
| Renderer | Lite (faster) | Legacy (slower) |
| Motion blur | No | Yes |
| Active development | ✅ Yes | ❌ No |
| Recommended | ✅ Yes | ❌ No |
