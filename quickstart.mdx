EB Client requires no installer, no Java runtime, and no account to start playing. The fastest path is downloading the single offline HTML file and opening it directly in your browser. If you want to host the client for others or benefit from asset caching, the web file bundle is the better choice. Both approaches are covered below.

<Note>
  **Browser requirement:** EB Client uses WebAssembly (WASM) to run the Minecraft 1.8 engine. Any modern browser with WebAssembly support is compatible — if your browser is reasonably up to date, it will work.
</Note>

## Option A — Offline HTML File (Recommended for Most Users)

This is the simplest path. The entire client is packed into one `.html` file that you download once and open locally, with no internet connection required after the initial download.

<Steps>
  <Step title="Download the offline HTML file">
    Grab the latest release from the `Offline Downloads` folder in the archive:

    ```
    Offline Downloads/[LATEST] EB Client Nextgen CU7.html
    ```

    Save it anywhere convenient — your desktop, a USB drive, or a dedicated folder. The file is large because it embeds the full asset pack inside the HTML.
  </Step>

  <Step title="Open the file in your browser">
    Double-click the downloaded `.html` file, or drag it onto an open browser window. You can also navigate to it manually:

    <Tabs>
      <Tab title="Chrome / Edge">
        Press <kbd>Ctrl</kbd>+<kbd>O</kbd> (Windows/Linux) or <kbd>⌘</kbd>+<kbd>O</kbd> (macOS), then select the `.html` file.
      </Tab>
      <Tab title="Firefox">
        Press <kbd>Ctrl</kbd>+<kbd>O</kbd> (Windows/Linux) or <kbd>⌘</kbd>+<kbd>O</kbd> (macOS), then select the `.html` file. Firefox may display a security prompt for local files — click **Allow** to continue.
      </Tab>
      <Tab title="Safari">
        Use **File → Open File…** from the menu bar and select the `.html` file.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Wait for the loading screen to complete">
    The first time you open the file the engine initialises and decompresses the asset pack from the embedded data. This typically takes **5 – 20 seconds** depending on your hardware. You will see a progress bar on a dark loading screen. Do not close the tab during this step.

    <Tip>
      Subsequent loads of the same file are faster because your browser caches the parsed WASM module. The very first load is always the slowest.
    </Tip>
  </Step>

  <Step title="Add a Microsoft account (optional)">
    After loading you will land on the main menu. EB Client supports Microsoft account authentication via device-code OAuth, so your in-game skin, username, and multiplayer profile match your purchased Minecraft account. The account login option is accessible from within the client settings UI.

    <Note>
      Adding a Microsoft account is entirely optional. You can play on servers that do not require online-mode authentication without linking any account.
    </Note>
  </Step>

  <Step title="Join your first server">
    From the main menu, click **Multiplayer**. EB Client uses a custom address scheme to distinguish Java servers (routed via WISP) from Eaglercraft relay servers.

    **Connecting to a Java Minecraft server:**
    ```
    java://play.example.net:25565
    ```
    Use the `java://` prefix followed by the server's hostname or IP and port. The client will tunnel this connection through the configured WISP proxy automatically.

    **Connecting to an Eaglercraft relay server:**
    ```
    wss://relay.deev.is/
    ```
    Paste the full `wss://` WebSocket URL directly. Three relays are built into the client and ready to use:

    | Relay | Address |
    |---|---|
    | lax1dude relay #1 | `wss://relay.deev.is/` |
    | lax1dude relay #2 | `wss://relay.lax1dude.net/` |
    | ayunami relay #1 | `wss://relay.shhnowisnottheti.me/` |

    Click **Join Server** once you have entered the address. The WISP proxy will establish the connection and you will load into the server normally.
  </Step>
</Steps>

## Option B — Web File Bundle (For Hosting)

Use the web file bundle if you want to host EB Client on a web server, a static hosting provider (Netlify, GitHub Pages, Cloudflare Pages, etc.), or your own infrastructure. The split format lets browsers cache the heavy `assets.epw` file independently, so returning visitors load much faster.

<Steps>
  <Step title="Grab the web file bundle">
    Copy the entire contents of the latest web bundle folder from the archive:

    ```
    Web Files (If you want to host yourself)/[LATEST] EB Client Nextgen CU7/
    ├── index.html
    ├── bootstrap.js
    ├── assets.epw
    └── favicon.png
    ```

    All four files must be kept in the same directory. Do not rename them — `bootstrap.js` and `assets.epw` are referenced by hard-coded paths in `index.html`.
  </Step>

  <Step title="Serve the folder from a web server">
    Upload the four files to the root (or a sub-directory) of your hosting provider. Any static file host works. Example using a local Python server for testing:

    ```bash
    # Python 3 — run from inside the bundle folder
    python3 -m http.server 8080
    ```

    Then open `http://localhost:8080` in your browser.

    <Warning>
      Do **not** open `index.html` as a `file://` URL when using the web bundle — relative asset loading requires an HTTP/HTTPS origin. Use the offline HTML file instead if you need local `file://` access.
    </Warning>
  </Step>

  <Step title="Open the hosted URL and proceed">
    Navigate to your hosted URL. From this point the experience is identical to the offline HTML approach: wait for the loading screen, optionally add a Microsoft account, and join a server using a `java://` or `wss://` address as described in Option A.
  </Step>
</Steps>

## Changing the WISP Proxy Server

The client ships with a default public WISP endpoint. If that endpoint is unavailable or you want to use your own proxy, you can update it from within the client settings UI. Look for the WISP server option in the settings screen, enter the full `wss://` URL of your WISP server, and save. The new proxy will be used for all subsequent `java://` connections.

<Tip>
  You can self-host a WISP proxy server to reduce latency or avoid reliance on public infrastructure. Any server implementing the open WISP protocol specification is compatible with EB Client.
</Tip>
