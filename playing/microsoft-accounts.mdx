EB Client supports Microsoft account authentication, allowing you to play on online-mode Java Edition servers as your legitimate Minecraft account. Authentication uses Microsoft's **device-code OAuth flow** — because EB Client runs entirely in the browser, it cannot open a pop-up login window, so you approve the sign-in on a separate device or tab instead. Once authenticated, your account credentials are stored locally in the browser so you can return without re-authenticating each session.

<Note>
  Online-mode Minecraft servers verify your session with Mojang's authentication servers. You must be signed in with a valid Microsoft account that owns Minecraft to join these servers. Offline-mode servers do not require an account.
</Note>

## Adding an Account

<Steps>
  <Step title="Open the Settings Panel">
    Click the **Settings** button in the EB Client page UI, or run the following in your browser's developer console:

    ```javascript
    window.showSettingsUI();
    ```

    The Wispcraft settings panel will appear.
  </Step>
  <Step title="Navigate to Microsoft Accounts">
    In the **Settings** tab, locate the **Microsoft Accounts** section. You will see a dropdown listing any accounts already stored, along with **Add** and **Remove** buttons.
  </Step>
  <Step title="Start the Device-Code Flow">
    Click **Add**. EB Client contacts Microsoft's OAuth2 device-code endpoint:

    ```
    https://login.microsoftonline.com/consumers/oauth2/v2.0/devicecode
    ```

    It requests the `XboxLive.signin offline_access` scope and retrieves a short-lived device code.
  </Step>
  <Step title="Authenticate on Microsoft's Website">
    The settings panel displays:
    - A **QR code** you can scan with your phone
    - A **verification URL** (e.g. `https://microsoft.com/devicelogin`)
    - A **one-time code** to enter on that page

    Open the URL on any device — your phone, another browser tab, or a separate computer — enter the code, and sign in with your Microsoft account.
  </Step>
  <Step title="Wait for Confirmation">
    EB Client polls Microsoft in the background. Once you complete sign-in, the client automatically exchanges the Microsoft access token through the full authentication chain:

    ```
    Microsoft access token
        → Xbox Live token
        → XSTS token
        → Minecraft access token
    ```

    The settings panel will show your account as active when the flow completes successfully.
  </Step>
</Steps>

## Authentication Flow Details

The complete token exchange happens entirely client-side inside the browser:

```
1. Device-code request  →  login.microsoftonline.com
2. User approves login  →  microsoft.com/devicelogin
3. Poll for token       →  login.microsoftonline.com (OAuth2 token endpoint)
4. Authenticate to XBL  →  user.auth.xboxlive.com
5. Exchange XSTS token  →  xsts.auth.xboxlive.com
6. Minecraft login      →  api.minecraftservices.com
```

No credentials are sent to EB Client's servers — all requests go directly from your browser to Microsoft and Mojang endpoints.

## Managing Multiple Accounts

EB Client can store more than one Microsoft account at a time, which is useful if you manage multiple Minecraft profiles.

### Switching Accounts

Open the settings panel and use the **account dropdown** in the Microsoft Accounts section to select the account you want to use. The selected account will be used for the next session you start.

You can also retrieve account information programmatically from the browser console:

```javascript
// List all stored Microsoft accounts
window.getLoggedInAccounts();

// Get the most recently used account
window.getLastUsedAccount();

// Get the current device-code flow data (if a sign-in is in progress)
window.getAuthCode();
```

### Removing an Account

Select the account you wish to remove from the dropdown, then click **Remove**. The account's stored tokens are deleted from the browser's local storage immediately.

<Warning>
  Removing an account is permanent within EB Client. You will need to go through the device-code flow again to re-add it.
</Warning>

## XSTS Error Reference

During the XSTS token exchange, Microsoft may return an error code if there is a problem with the Xbox Live account linked to your Microsoft profile. EB Client recognises the following errors and surfaces a human-readable message:

| Error Code | Meaning | Resolution |
|---|---|---|
| `2148916227` | Your account has been **banned from Xbox Live**. | Contact Xbox Support. EB Client cannot bypass this restriction. |
| `2148916233` | **No Xbox account is linked** to this Microsoft account. | Visit [xbox.com](https://xbox.com) and create or link an Xbox profile. |
| `2148916235` | **Xbox Live is not available** in your country or region. | Xbox Live and Minecraft online services are unavailable in your region. |
| `2148916236` | **Adult verification required** (varies by region). | Complete the age/identity verification on [account.microsoft.com](https://account.microsoft.com). |
| `2148916237` | **Adult verification required** (alternate enforcement). | Complete the age/identity verification on [account.microsoft.com](https://account.microsoft.com). |
| `2148916238` | Account is **under 18** and not in a family group. | A parent or guardian must add this account to a Microsoft Family group at [family.microsoft.com](https://family.microsoft.com). |

<Tip>
  If you see an error code not listed here, note the code and check the [Microsoft identity platform error codes](https://learn.microsoft.com/en-us/azure/active-directory/develop/reference-error-codes) documentation for further guidance.
</Tip>
