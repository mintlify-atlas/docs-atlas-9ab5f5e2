EB Client lets you play Eaglercraft — a browser port of Minecraft 1.8 — directly from a single HTML file or a self-hosted web page. It is powered by EaglercraftX and Wispcraft, which uses the WISP protocol to tunnel connections to both Eaglercraft relay servers and traditional Java Minecraft servers over WebSockets. No Java, no launcher, no install.

## What is EB Client?

EB Client packages the full EaglercraftX Minecraft 1.8 client into a standalone HTML page that runs entirely in your browser. The Nextgen line (the current branch) uses Wispcraft to proxy network traffic through a WISP-compatible WebSocket server, letting you connect to any Java Edition Minecraft server without a plugin or modification on the server side.

<Note>
  Always use the **Nextgen** build (currently CU7) for the best performance. The Legacy build — which includes motion blur — is no longer developed and is slower.
</Note>

## How it works

<Steps>
  <Step title="Open the HTML file">
    Download the latest `EB Client Nextgen CU7.html` file and open it in any modern browser, or navigate to a hosted instance.
  </Step>
  <Step title="Configure your WISP server">
    EB Client connects to Minecraft servers through a WISP relay. The default public relay is pre-configured — you can change it in Settings if you run your own.
  </Step>
  <Step title="Add a Microsoft account (optional)">
    Sign in with a Microsoft/Xbox Live account to play on servers that require online-mode authentication. Device-code login keeps credentials out of the browser.
  </Step>
  <Step title="Join a server">
    Enter a `java://` address to connect to any Java Edition server, or a `wss://` address for Eaglercraft relay servers.
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="Offline HTML Bundle" icon="file-code">
    The entire client ships as a single self-contained HTML file — save it locally and play without an internet connection to the host.
  </Card>
  <Card title="WISP Tunneling" icon="network-wired">
    Wispcraft routes TCP/TLS traffic through WebSockets using the open WISP protocol, enabling Java server connectivity from any browser.
  </Card>
  <Card title="Microsoft Auth" icon="microsoft">
    Device-code OAuth flow with Xbox Live means you can log in to your real Minecraft account without pasting passwords into a web page.
  </Card>
  <Card title="Self-Hostable" icon="box-archive">
    Every release ships with a separate web-file bundle (`index.html` + `bootstrap.js` + `assets.epw`) so you can host EB Client on your own infrastructure.
  </Card>
</CardGroup>
